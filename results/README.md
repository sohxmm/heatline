# Legacy results

The files in this directory belong to the original experiment. They used
different label and climatology assumptions and must not be quoted as the
corrected model's evidence. A snapshot is preserved in
`legacy/original-experiment.zip`.

Current measured results are in `artifacts/heatline/metrics.csv` and
`artifacts/heatline/runs.csv`; the interpretation is in
`docs/ACADEMIC_REPORT.md`. Current entry point: `python -m src.experiment`.
