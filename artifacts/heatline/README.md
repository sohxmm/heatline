# Current assessed experiment

Generated by `python -m src.seasonal_experiment`, using the corrected NumPy ANN and
declared `nagpur-grid-proxy-v1`. Do not mix these files with the legacy model
weights in the repository-root `models/` directory.

`model.json`, `history.json`, `experiments.json` and `learning.json` are shared by
FastAPI and the frontend. `outlook.json` contains independent Open-Meteo provider
forecasts and is refreshed by `scripts/fetch_weather_snapshot.py`. No live ANN
prediction is produced. `provenance.json` records input hashes and runtime versions.

`runs.csv` reports selection-period metrics for the fixed architecture/objective
grid and controlled learning-factor runs. `metrics.csv` reports retrospective
2019–2026 results. PR-AUC means average precision. Calibration fitting and F1
threshold selection use 2015–2018 only. Raw and transformed Brier scores are
provided; calibration is not guaranteed.

The seasonal v2 model trains on April–June 1981–2010 and is selected using May
2011–2014 average precision of a three-seed mean. Each member is one hidden layer
with explicit NumPy backpropagation. Platt scaling and F2/F1 operating thresholds
use May 2015–2018. `ensemble.json` identifies saved member weights; day traces
show each sigmoid computation and their arithmetic mean.

`provider_benchmark.json` is an independent NASA POWER experiment with a separate
target population; it does not replace the eight ERA5-positive evaluation days.
`source_audit.json` documents grid and reporting-window differences, original-cache
equivalence and a limited training-era station cross-check. The revised gains
remain exploratory because 2019–2026 outcomes were previously inspected.
