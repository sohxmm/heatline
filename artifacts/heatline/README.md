# Current assessed experiment

Generated by `python -m src.experiment`, using the corrected NumPy ANN and
declared `nagpur-grid-proxy-v1`. Do not mix these files with the legacy model
weights in the repository-root `models/` directory.

`model.json`, `history.json`, `experiments.json` and `learning.json` are shared by
FastAPI and the frontend. `outlook.json` contains independent Open-Meteo provider
forecasts and is refreshed by `scripts/fetch_weather_snapshot.py`. No live ANN
prediction is produced. `provenance.json` records input hashes and runtime versions.

`runs.csv` reports selection-period metrics for the fixed architecture/objective
grid and controlled learning-factor runs. `metrics.csv` reports retrospective
2019–2026 results. PR-AUC means average precision. Calibration fitting and F1
threshold selection use 2015–2018 only. Raw and transformed Brier scores are
provided; calibration is not guaranteed.

The model is selected using mean 2011–2014 average precision across three seeds,
then deployed with fixed seed 42. The retrospective results contain only eight
positive days; simpler baselines outperform the ANN on some metrics.
